# WiSE NYC Website

A simple website created for the WiSE NYC AI + GitHub workshop.

## About

WiSE NYC is a community for women interested in
software engineering, technology, and tech careers
in New York City.

## Workshop Project

The website displays several types of WiSE NYC events:

- AI
- Software Engineering
- Data
- Networking

The category filter buttons are visible, but the
filtering functionality has not been implemented yet.

During the workshop, we will use an AI coding assistant
to add this feature.

## Technology

- HTML
- CSS
- JavaScript

No frameworks or installation are required.

## Workshop Challenge

Ask your AI coding assistant:

> Add a category filter to the WiSE NYC website.
> Users should be able to filter events by AI,
> Software Engineering, Data, and Networking.
> Keep the existing event data unchanged.
> Make the smallest changes necessary and explain
> which files you modified.
